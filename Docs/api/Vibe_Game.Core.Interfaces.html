Table of Contents

Namespace Vibe_Game.Core.Interfaces

Classes

RunStats

Модель данных, представляющая статистику одной игровой сессии.

Interfaces

ICamera

Контракт для реализации камеры, обеспечивающий управление представлением мира, трансформацию координат и эффекты экрана.

ICameraShake

Интерфейс для реализации эффекта тряски камеры. Инкапсулирует логику расчета смещения и управления временем действия эффекта.

ICollidable

Определяет контракт для игровых сущностей, которые могут вступать в физические или триггерные взаимодействия с другими объектами.

ICollisionSystem

Интерфейс системы управления коллизиями. Отвечает за отслеживание объектов, пространственное индексирование и выявление столкновений между сущностями.

IGameStateService

Сервис управления глобальным состоянием игры. Предоставляет доступ к текущему состоянию и уведомляет подписчиков при его изменении.

IInputBindings

Интерфейс для управления привязками клавиш (Input Mapping). Позволяет абстрагировать игровые действия от конкретных физических клавиш, поддерживая переназначение и сохранение настроек управления.

IInputService

Сервис для обработки пользовательского ввода. Преобразует сырые события ввода (клавиатура, геймпад) в высокоуровневые игровые действия.

IItemEffect

Определяет контракт для эффектов предметов, которые могут изменять характеристики игрока. Используется для реализации бонусов, дебаффов и временных усилений.

IPlayerContentLoader

Контракт для сущностей, которым требуются внешние ресурсы (текстуры, звуки). Позволяет отделить логику загрузки от инициализации игрового объекта.

IPlayerRenderer

Контракт для отрисовки игрока. Позволяет инкапсулировать логику визуализации, анимации и трансформации спрайтов.

IStatsRepository

Интерфейс для взаимодействия с системой хранения статистики игровых сессий. Позволяет сохранять результаты пробегов и извлекать исторические данные.

IWallCollisionChecker

Определяет контракт для сервиса проверки столкновений игровых сущностей со стенами и статическими препятствиями уровня.

Enums

GameState

Перечисление возможных состояний игрового цикла.

InputAction

Перечисление доступных действий игрока.
