Базовый враг: здоровье, активация при входе в комнату, общий жизненный цикл. Конкретное поведение (как ходит, какая коллизия) — в наследниках через UpdateEnemy(GameTime). Наследует Entity: позиция, IsAlive, при желании Texture для отрисовки по умолчанию.
