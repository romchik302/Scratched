Table of Contents

Namespace Vibe_Game.Core.Services

Classes

GameStateService

Управления состоянием игры, отвечает за хранение текущего состояния и уведомление о его изменении.

GameplayAudio

Статический сервис для управления звуковыми эффектами (SFX) и фоновой музыкой (BGM) в игровом процессе. Обеспечивает плавные переходы между треками, управление громкостью и безопасную загрузку ассетов.

InputService

Сервис ввода, обеспечивающий обработку клавиатуры и мыши с поддержкой настраиваемых привязок действий.

LevelGenerator

Генератор уровней, отвечающий за создание процедурной структуры этажей, размещение комнат, назначение типов комнат и построение соединений между ними.

Room

Представляет отдельную комнату на сгенерированном этаже. Управляет сеткой тайлов (Tiles), логикой расстановки препятствий, декораций и интерактивных объектов (пьедесталы, кнопки, люки). Также хранит состояние комнаты (зачищена, заблокирована), её тип (Start, Battle, Boss, Treasure) и список находящихся внутри врагов.
